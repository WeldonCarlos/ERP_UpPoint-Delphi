# ERP UpPoint · Protótipo Delphi

Protótipo de interface desktop de ERP em Delphi, com menu principal e estrutura de conexão com banco.

## O que o projeto apresenta

- Menu com áreas de clientes, produtos, caixa, fornecedores e configurações.
- Indicação visual da opção selecionada.
- Interações de interface e encerramento da aplicação.
- Serviço de conexão e arquivo Firebird presente na estrutura.

## Tecnologias

Delphi · Object Pascal · VCL · FireDAC · Firebird

## Executar localmente

Clone o repositório e abra `ERPUpPoint.dproj` em uma instalação do Delphi para Windows com VCL e FireDAC. Configure o driver, a biblioteca cliente e a conexão local com o banco antes de compilar e executar pela IDE.
